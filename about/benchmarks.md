# 测速基准与实测环境规范 (Benchmarks)

> **机场专线云 (JichangZhuanxianYun.com) 压测硬件平台与工具链标准化白皮书**  
> 公开底层压测架构、运营商网络环境与自动化检测脚本，确保每一组测速数据均可复现、可验证。

## 🖥️ 1. 硬件环境与网络接入拓扑

为了消除传统家用路由器 CPU 瓶颈、光猫 NAT 性能损耗以及 Wi-Fi 无线信号干扰对测速造成的偏差，机场专线云采用了企业级标准化的压测硬件平台：

```
+-----------------------------------------------------------------------+
|                       机场专线云 标准化压测拓扑                       |
+-----------------------------------------------------------------------+
  [光猫 Bridge 桥接] ---> [双 2.5G 专用工控机] ---> [Docker 自动化压测容器]
   (千兆 FTTH 光纤)       (iStoreOS / OpenWrt)     (Speedtest / NextTrace)
```

- **专用压测硬件**：双 2.5G 网卡专用工控机（Intel x86-64 架构 / 多核高主频 CPU / 16GB DDR4 RAM / NVMe 高速固态）。
- **光猫 Bridge 桥接模式**：禁用光猫默认路由与 NAT 功能，将其设置为纯光电转换 Bridge 桥接模式。
- **软路由 PPPoE 拨号**：由工控机直接进行 PPPoE 拨号，获取公网 IPv4/IPv6 地址，消除局域网二次 NAT 转换与转发延迟。
- **全程 Cat6A 屏蔽网线**：客户端与网关之间采用 10Gbps 标称 Cat6A 六类屏蔽网线直连，阻断 Wi-Fi 频段抖动。

## 🌐 2. 三大运营商千兆直连链路覆盖

不同运营商在出境骨干网路线与节点拥堵程度上存在显著差异。本站部署了覆盖中国大陆三大主流运营商的千兆测试节点：

### 1. 中国电信 (China Telecom)
- **千兆 FTTH 下行 1000Mbps / 上行 100Mbps**
- **测试覆盖链路**：
  * **163 骨干网 (AS4134)**：测试普通公网直连与普通 BGP 中转在晚高峰的压测表现。
  * **CN2 GIA 精品网 (AS4809)**：对比测试企业级专线与电信顶级 CN2 线路在丢包率上的区别。

### 2. 中国联通 (China Unicom)
- **千兆 FTTH 下行 1000Mbps / 上行 100Mbps**
- **测试覆盖链路**：
  * **169 骨干网 (AS4837)**：测试联通主力出境线路的高并发吞吐能力。
  * **A网 / 精品网 (AS9929)**：测试高价值联通专线中转节点的延迟与稳定性。

### 3. 中国移动 (China Mobile)
- **千兆 FTTH 下行 1000Mbps / 上行 100Mbps**
- **测试覆盖链路**：
  * **CMIN2 精品网 (AS58807 / AS9808)**：测试移动最新一代 CMIN2 专线出口在晚高峰的抗丢包与低抖动表现。

## 🛠️ 3. 自动化测试工具链与检测模型

本站自主搭建了基于 Docker 容器化的 24 小时高频自动化测试工具链，主要包含以下三大核心模块：

### 1. NextTrace 路由跟踪与物理专线判定
- **工具**：[NextTrace (开源可视化路由跟踪工具)](https://github.com/nxtrace/NxtTrace)
- **作用**：向目标节点发送 ICMP/UDP 探针，精准解析回程 AS 跳数、过境 POP 点地理位置及 ICMP 响应延迟。
- **专线判定标准**：
  * **IPLC/IEPL 物理专线**：路由跳数极少（通常从国内入口点直接直连到香港/日本/新加坡落地点，中间无过境 GFW 节点跳数）。
  * **公网中转**：路由跳数较多，且在 163/AS4837 骨干网出口处可见明显的大网丢包与节点跳跃。

### 2. Docker 容器化 Speedtest-CLI 多线程并发取样
- **工具**：`ookla-speedtest-cli` 容器化镜像
- **测试逻辑**：
  * **低频日常监控**：每 2 小时自动对所有节点进行一次单线程与多线程（8 线程并发）Speedtest 带宽取样。
  * **晚高峰高压测试**：每日 20:00~23:00 期间，将取样频率提升至每 15 分钟一次，记录下行带宽峰值、上行速率及 RTT 延迟抖动。
  * **丢包率计算**：通过连续发送 100 个 ICMP/UDP 数据包，精确统计高压下的实时丢包百分比。

### 3. MediaUnlockTest 自动化解锁检测
- **工具**：`MediaUnlockTest` (自动化流媒体与 AI 权限检测)
- **检测目标**：
  * **AI 办公服务**：ChatGPT 4o / OpenAI Web / Claude 3.5 Sonnet / Google Gemini / Midjourney / Poe。
  * **流媒体平台**：YouTube Premium 区域 / Netflix 完整自制剧与版权剧 / Disney+ / HBO Max / Spotify。
- **风险值评估**：集成 IPQS (IP Quality Score) API 接口，自动检测节点落地 IP 的 Threat Score 风险分值（判断是否为机房 DataCenter IP 或纯净家宽 Residential IP）。
