# ❓ 知识问答 FAQ (常见问题解答)

---

### Q1：节点名称中的 0.5x / 1.0x / 2.0x 倍率是什么意思？
- **倍率的核心含义**：倍率代表使用该节点时扣除套餐流量的比例。
- **1.0x (标准倍率)**：消耗 10GB 流量即实际从套餐扣除 10GB 额度。
- **0.5x (低倍率优惠)**：消耗 10GB 流量实际仅扣除 5GB 额度，适合下载大文件或追剧。
- **2.0x / 3.0x (高倍率品质)**：对应更优质、成本更高的企业级 IPLC 专线或原生家宽 IP 节点。

---

### Q2：同一个账号可以多台设备同时在线使用吗？
- **套餐限制规则**：取决于购买的机场套餐规则（如云界线、大佬云、榴莲云完全不限制设备数；而环球梯清晰限制 3~10 台在线设备）。
- **安全防范提醒**：切勿公开或随意共享订阅链接，防止被他人非法蹭用导致连接数超限或账号被自动封禁。

---

### Q3：连接节点后能访问 Google，但打不开 ChatGPT / Netflix / TikTok 是为什么？
- **风控与封锁原因**：ChatGPT、Netflix、TikTok 等平台对数据中心（IDC）机房 IP 拥有极严格的风控机制与区域封锁。
- **解决方案**：请在客户端节点列表中，切换至专门标有“原生 IP / 解锁 / 流媒体 / AI 专用”标识的干净节点访问。

---

### Q4：规则模式（Rule）、全局模式（Global）和直连模式（Direct）有什么区别？
- **规则模式 (Rule / 智能分流 - 强烈推荐)**：国内流量（微信、百度、淘宝）走本地网络，不耗套餐流量且速度快；国外流量才走代理节点。
- **全局模式 (Global)**：强制所有流量（包括国内应用）全部经过代理节点，适合特殊调试或某些分流规则失效的场景。
- **直连模式 (Direct)**：关闭代理功能，所有网络请求均走本地网络。

---

### Q5：套餐流量是按自然月重置还是按账单周期重置？剩余流量会结转吗？
- **重置规则**：绝大多数机场按购买日的账单周期（如每月15号购买，则每月15号自动重置），少数固定每月1号重置。
- **结转与清零**：未用完的月度流量在周期末自动清零，不结转至下月。若流量提前用完，可在后台购买“流量重置包”或提前续费重置。

---

### Q6：为什么在测速网站测速很快，但看视频或玩游戏依然会卡顿？
- **峰值带宽 ≠ 低延迟/0丢包**：测速反映的是最高带宽，而看视频与外服游戏对“丢包率与延迟抖动”极度敏感。
- **卡顿因素**：晚高峰骨干网拥堵、本地 Wi-Fi 信号干扰、DNS 污染，或外服游戏未开启 `FullCone NAT` 节点导致 NatType 受限。

---

### Q7：使用代理后提示“系统时间与服务器不同步”打不开网页怎么办？
- **握手失败原因**：现代加密协议（如 VMess、TLS 握手）对系统时钟要求极严，若设备本地时间与标准时间误差超过 60 秒会导致握手拒绝。
- **解决方案**：在 Windows / Mac / 手机系统设置中，找到“日期与时间”，开启“自动设置时间 / 同步网络时间”即可恢复。

---

### Q8：订阅链接泄漏了怎么办？如何重置？
- **重置步骤**：
  1. 登录机场官网后台用户中心；
  2. 点击“重置订阅链接 / 重置 UUID / 重置 Token”；
  3. 重置后原旧订阅链接将瞬间失效；
  4. 在本地客户端删除旧订阅，重新导入新生成的订阅链接即可。

---

### Q9：开启代理后，国内常用应用（微信、网易云、淘宝等）很慢或提示异地登录？
- **问题原因**：分流规则未生效或误开了“全局代理模式”，导致国内应用的流量也绕道国外代理节点走了一圈。
- **解决方案**：将客户端模式切换为“规则模式 (Rule)”，并在客户端设置中更新最新的绕过大陆（Bypass LAN & China）规则集。

---

### Q10：支持退款吗？如果遇到不可抗力或节点大面积维护如何补偿？
- **退款政策**：代理服务属于虚拟商品，原则上售出不退，因此强烈建议新手**优先选择月付**进行试用体验。
- **故障补偿**：若遭遇海缆中断、主干网维护等导致长达数小时的大面积故障，优质机场运维会在恢复后提供**套餐时长顺延、发放折扣代金券或补发流量**作为补偿。

---

### Q11：SS / Vmess / Trojan / Hysteria2 协议有什么区别？新手怎么选？
- **Shadowsocks (SS/SSR)**：经典轻量协议，在 IPLC/IEPL 专线中延迟最低；但在公网直连线路上容易被防火墙特征识别。
- **Vmess / Vless (V2Ray)**：具备极强伪装能力的经典协议，适合各种中转与公网线路，稳定性极佳。
- **Trojan**：模仿标准 HTTPS 网站加密流量，伪装度高。
- **Hysteria2 / TUIC**：2026 最强的 UDP 新协议，专为弱网环境设计，在丢包率高的网络下依然能榨干带宽，抗封锁能力强。
- **选购建议**：专线线路选 SS/Vmess 即可；直连或移动网络优先选 Hysteria2。

---

### Q12：什么是 IPLC/IEPL 专线？为什么比直连线路稳定？
- **IPLC/IEPL** 是运营商提供的点对点内网专线，**不经过国家防火长城 (GFW) 的公网检测**。
- 普通直连线路在晚高峰（20:00-23:00）极易受到公网 QOS 限速丢包；而 IEPL 专线拥有一条独立物理管道，能做到 24 小时超低延迟与 0 丢包。

### Q13：各大平台推荐使用什么科学上网客户端？
- **Windows**：首推 `Clash Verge Rev` (界面现代且支持自定义规则) 或 `Nyanpasu`。
- **macOS**：推荐 `Clash Verge Rev` 或 `ClashX Meta`。
- **iOS (iPhone/iPad)**：推荐 `Shadowrocket (小火箭)`、`Stash` 或 `Loon`。
- **Android**：推荐 `Clash Meta for Android` 或 `Surfboard (冲浪板)`。

### Q14：疑难排查：订阅无法更新 / 节点连接超时怎么解决？
1. **检查系统时间**：电脑/手机系统时间若与标准时间相差超过1分钟，V2Ray/Vmess 校验会直接报错。
2. **检查规则模式设置**：确保客户端处于“Rule / 规则模式”而非“Direct / 直连模式”。
3. **更换订阅域名**：若更新订阅失败，可在机场后台开启“订阅转换”或联系客服获取备用链接。
