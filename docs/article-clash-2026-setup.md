# 📦 2026 Clash / Sing-box 客户端配置与节点订阅全流程教程

> 本教程为您提供全平台（Windows、macOS、Android、iOS）快速配置 Clash / Sing-box 并导入机场订阅链接的保姆级指南。

---

## ⚡ 第一步：获取机场订阅链接

1. 注册并登录您选择的机场（如 [云界线](https://9625mofan01.yunjiexianaff.com/#/?code=OOYhSj0L) 或 [大佬云](https://mofanvip01.dalaoyunaff.com/#/?code=QT2rqp5V)）。
2. 在用户后台面板中，点击 **【一键导入 Clash 订阅】** 或 **【复制订阅地址】**。

---

## 💻 第二步：Windows / macOS 客户端配置 (Clash Verge Rev)

1. 打开 **Clash Verge Rev** 客户端。
2. 点击左侧菜单栏 **【Profiles (订阅)】**。
3. 在上方文本框中粘贴刚才复制的订阅 URL，点击 **【Import (导入)】**。
4. 导入成功后，右键选中该订阅并点击 **【Select (选中)】**。
5. 切换到左侧 **【Proxies (代理)】**，将代理模式设置为 **Rule (规则模式)**。
6. 打开左下角 **System Proxy (系统代理)** 开关，即可成功开启代理。

---

## 📱 第三步：iOS 苹果手机配置 (Shadowrocket 小火箭)

1. 打开 **Shadowrocket** 软件。
2. 点击右上角 **`+`** 加号。
3. 类型选择 **`Subscribe (订阅)`**，在 URL 处粘贴订阅链接。
4. 点击右上角 **Save (保存)**，下拉刷新订阅列表。
5. 选择任意节点（如香港 IPLC 专线），勾选连通。
6. 打开顶部 **未连接 / 已连接** 总开关，首次使用允许添加 VPN 配置即可。

---

## 💡 常见配置错误排查
- **系统时间不同步**：若更新订阅失败或节点 Ping 为 -1，请去系统设置开启“自动同步网络时间”。
- **模式选错**：切勿保持为 Direct（直连）或 Global（全局），务必选择 **Rule / 规则模式**。
