## 🛠️ 5. 云界线 Clash / Sing-box 客户端配置与订阅导入指南

### 1. 它是传统 VPN 还是专线代理？
- **技术区别**：传统 VPN 全局接管所有网络且容易被 GFW 深度包检测 (DPI) 识别阻断；而云界线属于**物理专线代理集群 (IPLC + VLESS)**，配合 Clash / Sing-box 等现代化内核，可实现国内直连、国外走专线的**智能规则分流**。

### 2. Windows / macOS 快速配置 (推荐 Clash Verge Rev)
1. 登录云界线后台，进入“仪表盘”或“我的订阅”；
2. 找到“一键导入订阅”按钮，选择 **Clash 订阅** 并复制链接；
3. 打开 **Clash Verge Rev**（可在本站 [客户端下载工具箱](/toolbox) 下载），点击左侧 `Subscribers (订阅)`；
4. 粘贴订阅链接并点击 `Save (保存)` 即可拉取最新专线节点；
5. 在左侧 `Proxies (代理)` 面板中，选择 `Rule (规则模式)`，节点选择 `自动选择` 或延迟最低的 `香港 01 [优质专线]`。

### 3. iOS / Android 手机端配置
