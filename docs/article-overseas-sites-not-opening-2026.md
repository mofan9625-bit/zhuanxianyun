# 🌍 2026 海外网站打不开 / 连接超时排查手册

---

## 🛠️ 综合排查 5 步法

1. **确定客户端开启了系统代理**：确认图标变亮或开启了 TUN 模式。
2. **确认分流模式为 Rule 规则模式**。
3. **检查 Telegram / Discord 特殊端口**：某些软件需开启 TUN 增强模式或手动在软件内设置 SOCKS5 本地代理端口 (`127.0.0.1:7897`)。
4. **更换备用节点**。
5. **尝试重启客户端与清理 DNS 缓存** (`ipconfig /flushdns`)。
