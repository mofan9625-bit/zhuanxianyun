# 评测标准与评分权重体系 (Methodology)

> **机场专线云 (JichangZhuanxianYun.com) 独立量化打分模型与评估框架**  
> 剔除公关宣传水分，基于真实数据与晚高峰高压测试，建立客观中立的评测标准。

---

## 📐 1. 量化打分模型与核心权重占比

为确保评测结果兼具科学性与客观性，机场专线云采用百分制多维度加权打分模型。核心评价维度与权重占比如下：

| 评价维度 | 权重占比 | 核心考核指标与测试方法 | 评分细则说明 |
| :--- | :---: | :--- | :--- |
| **晚高峰抗压稳定性** | **35%** | 每日 20:00~23:00 骨干网拥堵时段压测；丢包率、延迟抖动、TCP/UDP 吞吐速率、YouTube 4K/8K 缓冲秒开能力。 | 丢包率 < 1% 得满分；丢包率 1%~5% 递减扣分；丢包率 > 15% 或频繁断连判定为严重不合格。 |
| **真实物理专线纯度与协议支持** | **25%** | NextTrace 路由跟踪回程 AS 跳数检测；是否为真实 IPLC/IEPL 物理内网专线；支持 Clash/Sing-box/Hysteria2/TUIC/Shadowsocks 协议。 | 真实物理 IPLC/IEPL 满分；公网中转冒充专线扣大分；支持新一代弱网协议（H2/TUIC）有额外加分。 |
| **落地 IP 纯净度与 AI/流媒体解锁** | **15%** | 节点落地 IP 纯净度（住宅/原生 IP 占比）；ChatGPT 4o / Claude 3.5 / Netflix / Disney+ / Midjourney / Google Gemini 零阻断解锁率。 | 全节点完美解锁 ChatGPT 及 4K 流媒体得满分；频繁出现 1020 / Access Denied 或 IP 被标记为机房 IP 则扣分。 |
| **计费透明度与无隐式倍率** | **15%** | 节点扣量倍率透明度；是否存在虚高 5x/10x 隐形扣量陷阱；套餐流量实打实 1x 扣费比例与设备并发限制。 | 100% 节点为 1x 真实倍率得满分；暗藏 3x~10x 恶意高倍率扣分；限制设备连接数过严扣分。 |
| **运维 SLA 响应与工单时效** | **10%** | 节点故障修复速度；客服 Telegram 群组 / 工单响应时间（< 1 小时）；公告透明度与节点维护主动通知机制。 | 工单 1 小时内响应且有明确故障公告得满分；工单超过 24 小时无人回复或常态化失联扣分。 |

## 🚫 2. “一票否决”下架与黑名单拉黑机制

除了日常量化评分外，机场专线云设立了严格的**“一票否决”（Veto Rule）触发条款**。无论某服务商历史得分多高，一旦触发以下任意一条红线，将**立即取消推荐、全站同步下架并列入【跑路避坑监控黑榜】**：

```
                +---------------------------------+
                |   触发“一票否决”红线警告         |
                +---------------------------------+
                                |
       +------------------------+------------------------+
       |                        |                        |
       v                        v                        v
[虚标假专线欺诈]         [暗藏恶意高倍率]         [群组禁言/失联跑路前兆]
       |                        |                        |
       +------------------------+------------------------+
                                |
                                v
               +----------------------------------+
               | 立即下架 + 列入跑路黑榜 + 警告用户 |
               +----------------------------------+
```

### ❌ 1. 虚标假专线一票否决
- **现象**：宣传为“全节点 IPLC/IEPL 国际专线”，但通过链路分析发现其实际使用公网直连或普通 VPS 中转，过墙时大量丢包甚至被封锁。
- **处理**：直接认定为虚假宣传与欺诈行为，评分归零并下架。

### ❌ 2. 暗藏恶意倍率一票否决
- **现象**：上线初期宣传低价，而后在用户不知情的情况下悄悄将常用节点倍率调高至 5x、10x 甚至 20x，导致用户流量在短时间内被迅速扣光。
- **处理**：判定为恶意扣量套路，直接列入不可信任黑名单。

### ❌ 3. 官方群组禁言与失联跑路前兆一票否决
- **现象**：服务商 Telegram 官方交流群突然解散、全员禁言，客服工单超过 48 小时无人回复，或出现大量用户投诉节点无法连通且官方无回应。
- **处理**：判定为极高风险的跑路前兆，第一时间发布【跑路风险预警】，全站下架相关入口并提示读者停止续费。

## 🔬 3. 评测周期与动态更新规范

1. **24 小时自动化探针监控**  
   本站部署的自动化测试探针会对各上榜服务商的核心节点进行 24 小时持续 Ping 延迟与 TCP 连通性监测。
2. **每周晚高峰人工复测**  
   每周选取 2~3 个晚高峰时段（20:00 - 23:00），由测试人员进行人工 Speedtest 测速与 4K/8K 视频播放实时抓包。
3. **每月榜单动态调整**  
   每月初根据过去 30 天的综合评分数据，重新计算加权得分，更新《核心稳定机场精选对比表》的排名与评级。
