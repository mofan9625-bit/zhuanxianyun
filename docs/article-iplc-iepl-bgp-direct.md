# 💡 IPLC/IEPL 专线、BGP 中转与直连线路有什么区别？

> 在选购科学上网机场套餐时，经常会看到 IPLC 专线、IEPL 专线、BGP 中转、直连等各种专业词汇。本文为您深度拆解它们的物理结构与性能差异。

---

## 🏗️ 一、四大线路架构物理拓扑对比

### 1. IPLC (International Private Leased Circuit - 国际私有专线)
- **物理架构**：运营商提供的点对点跨国内网物理光纤专线。
- **GFW 过境**：**完全不经过 GFW (防火长城)** 公网检测，在深圳/上海内网入口直接通过海底光缆传输至香港/日本落地点。
- **优点**：24 小时超低延迟、晚高峰 0 丢包、100% 抗封锁。
- **缺点**：带宽成本极为高昂。

### 2. IEPL (International Ethernet Private Line - 国际以太网专线)
- **物理架构**：基于二层以太网技术的专线，性能与 IPLC 极其类似。
- **特点**：同样不经过 GFW 公网检测，延迟抖动极小。

### 3. BGP 多线中转 (BGP Transit)
- **物理架构**：国内入口采用 BGP 多线服务器（电信/联通/移动三网直连），中转机房加密后通过公网骨干网发往海外 VPS。
- **特点**：速度快、带宽大、性价比高，但晚高峰依然受公网骨干网拥堵影响。

### 4. 普通公网直连 (Direct / 163 / AS4837)
- **物理架构**：用户的流量直接通过普通国际出口过墙。
- **特点**：成本极低，但在晚高峰（20:00-23:00）QoS 丢包率高达 30%~50%，且节点 IP 极易被墙。
