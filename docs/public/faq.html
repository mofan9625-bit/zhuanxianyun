Module 02 / 零基础 FAQ

知识问答库与客户端配置指南

通俗解析 SS/Vmess/Hysteria2 区别，直击订阅失败与节点超时排查

Q1. 节点名称中的 0.5x / 1.0x / 2.0x 倍率是什么意思？ ▼

倍率代表使用节点时扣除套餐流量的比例。例如：

  • 1.0x (标准倍率)： 消耗 10GB 流量即实际扣除 10GB 额度；
  • 0.5x (低倍率优惠)： 消耗 10GB 流量实际仅扣除 5GB 额度，适合大文件下载；
  • 2.0x / 3.0x (高倍率品质)： 对应成本更高、品质更优的企业级 IPLC 专线或原生家宽 IP 节点。
Q2. 同一个账号可以多台设备同时在线使用吗？ ▼

这取决于您购买的套餐规则：

  • 不限设备套餐 (如云界线、大佬云、榴莲云)： 可以在您的多台手机、电脑、平板上自由同时在线使用；
  • 限制设备数套餐 (如环球梯 限制3~10台)： 严格限制公网 IP 及客户端在线数，超额会导致临时断连；

⚠️ 安全提示： 切勿将订阅链接公开或借给他人，防止被非法蹭用导致超限或封禁。

Q3. 连接节点后能访问 Google，但打不开 ChatGPT / Netflix / TikTok 是为什么？ ▼

ChatGPT、Netflix 及 TikTok 等平台拥有极严格的风控机制，会自动封锁常见的公网机房 IP。

解决方案： 请在客户端节点列表中，切换至标注有 原生 IP、解锁、流媒体 或 AI 专用 标识的干净节点即可正常访问。

Q4. 规则模式（Rule）、全局模式（Global）和直连模式（Direct）有什么区别？ ▼
  • 规则模式 (Rule / 智能分流 - 强烈推荐)： 自动识别流量。国内应用（微信、百度、淘宝）走本地网络（不耗流量且速度快），国外网站（Google、YouTube）才走代理；
  • 全局模式 (Global)： 强制所有网络流量全部经过代理节点，适合特殊调试或分流规则失效时使用；
  • 直连模式 (Direct)： 关闭代理，所有流量均走本地网络。
Q5. 套餐流量是按自然月重置还是按账单周期重置？剩余流量会结转吗？ ▼

重置规则： 绝大多数机场按购买日的账单周期（如每月15号购买，则每月15号重置刷新），少数固定每月1号重置。

结转与补充： 未用完的流量在周期末自动清零，不结转至下月。若流量提前用完，可在后台购买“流量重置包”或提前续费重置。

Q6. 为什么在测速网站测速很快，但看视频或玩游戏依然会卡顿？ ▼

测速网站测出的“最高峰值带宽”并不等于实际体验：

  1. 延迟与丢包： 视频与游戏对“丢包率与延迟抖动”极度敏感，晚高峰骨干网拥堵会导致丢包卡顿；
  2. 本地网络： 本地 Wi-Fi 信号干扰或 DNS 污染；
  3. 游戏 FullCone： 外服游戏连线需要节点支持 FullCone NAT，否则会导致 NatType 受限。
Q7. 使用代理后提示“系统时间与服务器不同步”打不开网页怎么办？ ▼

现代加密协议（如 VMess、TLS 握手）对系统时钟有严格要求。若本地设备时间与标准时间误差超过 60 秒，服务器会直接拒绝握手导致断网。

解决方案： 打开 Windows / Mac / 手机系统设置 -> “日期与时间” -> 开启 “自动设置时间 / 同步网络时间” 即可恢复。

Q8. 订阅链接泄漏了怎么办？如何重置？ ▼
  1. 登录机场官网后台用户中心；
  2. 点击 “重置订阅链接 / 重置 UUID / 重置 Token” 按钮；
  3. 重置后旧的订阅链接将瞬间失效；
  4. 在客户端中删除旧订阅，重新导入新生成的订阅链接即可。
Q9. 开启代理后，国内常用应用（微信、网易云、淘宝等）很慢或提示异地登录？ ▼

通常是因为误开启了“全局模式 (Global)”，导致国内应用流量也绕道国外节点走了一圈。

解决方案： 将客户端模式切换为 “规则模式 (Rule)”，并在客户端设置中选择并更新“绕过大陆 (Bypass LAN & China)”分流规则。

Q10. 支持退款吗？如果遇到不可抗力或节点大面积维护如何补偿？ ▼

退款政策： 网络代理属于虚拟商品，原则上售出不退，因此强烈建议新手优先选择月付进行测试；

故障补偿： 若遇到海缆中断、主干网维护导致大面积故障，优质机场运维团队会在恢复后提供套餐时长顺延、发放折扣代金券或补发流量作为补偿。

Q11. SS / Vmess / Trojan / Hysteria2 协议有什么区别？新手怎么选？ ▼

通俗来说：

  • Shadowsocks (SS/SSR)： 经典老牌协议，轻量高效，在 IPLC/IEPL 专线中延迟最低；但在普通直连链路上容易被识别。
  • Vmess / Vless (V2Ray)： 具备极强伪装能力的经典协议，适合各种中转与公网线路，稳定性好。
  • Trojan： 伪装成正常的 HTTPS 网站流量，特征极隐蔽。
  • Hysteria2 / TUIC： 2026 最火的 UDP 新协议，专为弱网环境优化，即使在网络拥堵、丢包高的环境下也能榨干带宽，抗封锁能力强。

选购建议： 专线线路选 SS/Vmess 即可；直连或移动网络优先选 Hysteria2。

Q12. 什么是 IPLC/IEPL 专线？为什么比直连线路稳定？ ▼

IPLC (国际专线) & IEPL (国际以太网专线)： 是指由电信/联通/移动等运营商提供的点对点局域网企业专线。特点是不经过国家防火长城 (GFW) 的公网检测与过滤。

直连线路在晚高峰 (20:00-23:00) 容易被公网 QOS 限速丢包甚至封锁 IP；而 IEPL 专线拥有独立物理通道，因此能保证 24 小时超低延迟与 0 丢包。

Q13. 客户端如何选择？各大平台推荐哪个软件？ ▼
  • Windows： 首推 Clash Verge Rev (界面现代支持自定义规则) 或 Nyanpasu。
  • macOS： 推荐 Clash Verge Rev 或 ClashX Meta。
  • iOS (iPhone/iPad)： 推荐 Shadowrocket (小火箭)、Stash 或 Loon。
  • Android： 推荐 Clash Meta for Android 或 Surfboard (冲浪板)。
Q14. 疑难排查：订阅无法更新 / 节点连接超时怎么解决？ ▼
  1. 检查本地时间同步： 电脑/手机系统时间若与标准时间相差超过1分钟，V2Ray/Vmess 校验会直接失效报错。请打开系统“自动校准时间”。
  2. 检查规则模式设置： 确保客户端处于“Rule / 规则模式”而非“Direct / 直连模式”。
  3. 更换订阅下载域名： 若更新订阅失败，可在机场后台开启“订阅转换”或使用备用订阅节点。
